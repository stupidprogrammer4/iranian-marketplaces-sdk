# مسیر یادگیری Iranian Marketplaces SDK

با این SDK می‌توانید از پایتون به دیجی‌کالا، اسنپ‌شاپ، باسلام و تپسی‌شاپ متصل شوید.
برای شروع، آشنایی پایه با پایتون و توکن دسترسی مارکت‌پلیس موردنظر کافی است.

## قدم‌به‌قدم

| گام | درس | در پایان می‌توانید… |
| --- | --- | --- |
| ۱ | [شروع سریع](getting-started.md) | SDK را نصب کنید، کلاینت بسازید و اولین پاسخ را بخوانید. |
| ۲ | [مدل‌ها و فیلترها](guides/models-and-queries.md) | ورودی معتبر بسازید و فیلدهای پاسخ را استفاده کنید. |
| ۳ | [صفحه‌بندی](guides/pagination.md) | چند صفحهٔ داده را با توجه به روش هر مارکت‌پلیس بخوانید. |
| ۴ | [کار با async](guides/async.md) | فراخوانی SDK را در برنامهٔ غیرهمگام اجرا کنید. |

## ادامه بر اساس مارکت‌پلیس

- [دیجی‌کالا](digikala/README.md): اتصال، کالا و سفارش، تغییر موجودی و فایل‌ها.
- [اسنپ‌شاپ](marketplaces/snapp.md): محصولات، سفارش‌ها و cursor.
- [باسلام](marketplaces/basalam.md): محصولات، مرسوله‌ها و تخفیف‌ها.
- [تپسی‌شاپ](marketplaces/tapsi.md): محصولات، سفارش‌ها و نتیجهٔ تغییرات گروهی.

## تمرین و مرجع

برای دیدن برنامهٔ کامل، [مثال‌های قابل‌اجرا](../examples/README.md) را باز کنید.
برای پیدا کردن عملیات مشخص دیجی‌کالا، به [مرجع متدها](reference/digikala-endpoints.md) بروید.

**پیشنهاد برای اولین تمرین:** درس اول را بخوانید، نمونهٔ sync مارکت‌پلیس خود را اجرا کنید
و بعد با تغییر اندازهٔ صفحه در مدل query، تعداد نتیجه‌ها را کمتر کنید.
